# Formulaire_saisi

Petit projet front‑end qui fournit une page HTML et un script JavaScript pour gérer la saisie d’un formulaire (validation et interactions côté client).

## Fonctionnalités
- Interface HTML simple pour saisir des données.
- Logique JavaScript pour gérer la saisie et le comportement du formulaire (validation, réactions aux événements).
- Code léger et facile à lire / étendre.

## Technologies
- JavaScript (~88%)
- HTML (~12%)

## Structure du dépôt
- index.html — page d’entrée contenant le formulaire et l’inclusion du script.
- saisie.js — logique JavaScript principale (gestion des événements et validation).
- README.md — (ce fichier)

## Prérequis
Un navigateur web moderne suffit. Pour un test local plus propre, il est recommandé de servir le dossier via un serveur HTTP local (ex. python3 -m http.server 8000).

## Installation / Exécution
1. git clone https://github.com/TahirAbdou/Formulaire_saisi.git
2. cd Formulaire_saisi
3. Ouvrir index.html dans un navigateur ou lancer un serveur local.
